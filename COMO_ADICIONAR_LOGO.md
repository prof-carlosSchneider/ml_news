# 🎨 GUIA: Como Colocar a Nova Logo no Site

## 📋 Você Tem a Imagem da Logo (Peixe/ML)

Siga os passos abaixo para colocar a nova logo no site!

---

## 🚀 PASSO 1: Preparar a Imagem

### Opção A - Logo Local (RECOMENDADO)

1. A imagem do peixe/ML que você tem
2. **Renomeie para:** `logo-ml-news.png`
3. **Coloque na pasta:** 
   ```
   c:\Users\aluno\Downloads\MLnews\
   ```
   (mesma pasta que index.html)

**Estrutura esperada:**
```
MLnews/
├── admin.html          ← painel administrativo
├── index.html          ← portal principal
├── style.css
├── script.js
└── logo-ml-news.png    ← AQUI! (sua nova logo)
```

### Opção B - Logo Online

Se preferir não colocar arquivo local:
1. Faça upload em: https://imgur.com ou https://imgbb.com
2. Copie o link
3. Use o link completo no painel (veja Passo 3)

---

## 🔑 PASSO 2: Fazer Login no Painel

1. Abra: `admin.html` no navegador
2. **Usuário:** `admin`
3. **Senha:** `@mlnews1`
4. Clique em "**Entrar no painel**"

```
┌─────────────────────────────────────┐
│ Acesso do Administrador             │
├─────────────────────────────────────┤
│ Usuário: [admin_____________]       │
│ Senha:   [*****************]        │
│         [Entrar no painel]          │
└─────────────────────────────────────┘
```

---

## 🖼️ PASSO 3: Adicionar a Logo no Gerenciador

Após fazer login, você verá o painel com várias seções.

**Procure por:** "🖼️ Gerenciador de Imagens"

### Dentro do Gerenciador:

Você verá: **Logo e Imagens Principais**

```
┌─ Logo e Imagens Principais ──────────┐
│                                      │
│ 🎯 URL da Logo                       │
│ (recomendado: PNG com fundo)        │
│ [logo-ml-news.png________]           │
│                                      │
│ ┌─ Preview da logo ───────────────┐ │
│ │                                  │ │
│ │      [sua logo aparece aqui]    │ │
│ │                                  │ │
│ └──────────────────────────────────┘ │
│                                      │
└──────────────────────────────────────┘
```

---

## 📝 PASSO 4: Escrever a URL da Logo

No campo **"🎯 URL da Logo"**, escreva:

### Se colocou arquivo local:
```
logo-ml-news.png
```

### Se colocou online:
```
https://i.imgur.com/xxxxxx.png
```
(ou outro site)

---

## 👀 PASSO 5: Ver o Preview

Após digitar a URL:

1. Você verá um preview da logo aparecer abaixo ✨
2. Se a logo aparecer → tudo ok!
3. Se não aparecer → verifique a URL

```
┌─ Preview da logo ────────────────┐
│                                  │
│      [🎣ML News em destaque]     │
│                                  │
│     (A logo aparecerá aqui!)     │
│                                  │
└──────────────────────────────────┘
```

---

## 💾 PASSO 6: Salvar as Alterações

Vá até o **final da página** e clique em:

```
┌──────────────────────────────────────┐
│  ✓ Salvar Todas as Alterações      │
│         (botão VERDE)                │
└──────────────────────────────────────┘
```

Você verá a mensagem:
```
✓ Alterações salvas com sucesso!
```

---

## 🌐 PASSO 7: Ver a Logo no Portal

Agora a logo está salva! Para vê-la no site:

1. Abra o **index.html** em uma **nova aba**
2. **Recarregue a página** (pressione **F5**)
3. A logo aparecerá no topo do site! 🎉

### A logo agora terá:
- **Tamanho:** 150x70 pixels (maior, sem cortes!)
- **Posição:** Canto superior esquerdo
- **Comportamento:** Clicável, volta para início

---

## ⚙️ DICAS IMPORTANTES

### ✅ Formato Correto
- **Tipo:** PNG (com fundo transparente, recomendado)
- **Tamanho mínimo:** 300x150 pixels
- **Tamanho ideal:** 600x300 pixels ou maior
- **Peso máximo:** 500KB

### ✅ URL Válida
Se usar URL online:
- Deve começar com: `http://` ou `https://`
- Exemplo: `https://imgur.com/xxxxxx.png` ✅
- Errado: `imgur.com/xxxxxx.png` ❌

### ✅ Se não aparecer
1. Verifique se a URL está correta
2. Copie a URL em uma aba nova (deve aparecer a imagem)
3. Verifique se o navegador permite imagens
4. Limpe o cache (Ctrl+Shift+Delete)

## 🆘 Problemas Comuns

### "A logo não aparece no preview"
- [ ] URL está correta?
- [ ] Começa com `http://` ou `https://`?
- [ ] Salvou as alterações?
- [ ] Recarregou a página (F5)?

### "A logo aparece cortada"
- Não! Aumentamos para 150x70px
- Ela não deve cortar mais
- Se cortar, verifique as proporções da imagem

### "Esqueci a senha"
- Padrão: `@mlnews1`
- Se não funcionar, entre em contato com admin

### "As alterações desapareceram"
- As mudanças são salvas no seu navegador
- Se limpou o cache/histórico, perdeu
- Faça backup salvando os dados!
