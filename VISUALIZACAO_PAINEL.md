## 🌟 Destaques de Design

### Tipografia
```
Títulos (h1, h2, h3):
├─ Família: "Barlow Condensed"
├─ Peso: 800
├─ Tamanho (h2): 28px
├─ Transform: uppercase
└─ Letter-spacing: 0.5px

Corpo:
├─ Família: "Inter", Arial
├─ Peso: 400-500
├─ Tamanho: 14-16px
└─ Line-height: 1.6

Labels:
├─ Peso: 700
├─ Tamanho: 12px
├─ Transform: uppercase
└─ Letter-spacing: 0.5px
```

### Animações
```
Botões:
├─ Hover: translateY(-2px)
├─ Duração: 0.3s
└─ Easing: ease

Inputs/Textareas:
├─ Focus: border-color (vermelho)
├─ Focus: box-shadow (interna)
├─ Duração: 0.3s
└─ Easing: ease
```
