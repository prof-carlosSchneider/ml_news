## ✋ PASSO 1: PREPARE A LOGO (1 minuto)

### Você tem a imagem?
✅ Sim, tenho o peixe/ML

### Fazer agora:
```
1. Pegue a imagem da logo
   └─ (você tem na pasta de downloads ou anexo)

2. Renomeie para:
   └─ logo-ml-news.png
   
   Importante:
   ├─ Exatamente esse nome!
   ├─ Extensão: .png
   ├─ Letras minúsculas
   └─ Sem espaços

3. Coloque na pasta:
   └─ c:\Users\aluno\Downloads\MLnews\
   
   (mesma pasta que index.html!)
```

## 🎨 PASSO 4: ADICIONE A LOGO (2 minutos)

### Você verá muitas seções. PROCURE POR:

```
🖼️ GERENCIADOR DE IMAGENS
```

### Dentro dessa seção, procure por:
```
🎯 URL da Logo
(recomendado: PNG com fundo transparente)
```

### Fazer agora:

```
1. Encontre o campo:
   └─ [logo-ml-news.png_______________________]

2. Clique dentro do campo
3. Apague tudo (Ctrl+A, Delete)
4. Digite:
   └─ logo-ml-news.png

5. Pressione TAB ou clique fora do campo
6. Veja o PREVIEW aparecer abaixo! ✨
   └─ (A logo aparecerá em uma caixa)
```

## 💾 PASSO 5: SALVE TUDO (1 minuto)

### Fazer agora:

```

   └─ ✓ Alterações salvas com sucesso!

5. Pronto! 🎉
```

## 🎯 SE ALGO NÃO APARECER

### "A logo não aparece no preview"
```
1. Verifique o nome do arquivo
   └─ Deve ser EXATAMENTE: logo-ml-news.png
   
2. Verifique a pasta
   └─ Deve estar em: MLnews/
   └─ (mesma pasta que index.html)

3. Se tiver feito tudo certo:
   └─ Limpe o cache (Ctrl+Shift+Delete)
   └─ Recarregue (F5)
   └─ Tente de novo
```

### "Esqueci a senha"
```
A senha é: @mlnews1
(aquele arroba antes)
```

### "Não aparece nada depois que salvo"
```
1. Recarregue o index.html (F5)
2. Tudo deve aparecer
```
